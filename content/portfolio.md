## Problem
Many personal portfolios rely on heavy frameworks for simple static content, resulting in bloated bundles and unnecessary load times. A portfolio should be immediate and accessible, prioritizing content over a complex technology stack.

## Solution
This project uses semantic HTML5 and modern CSS features to create an interactive experience without client-side JavaScript dependencies. The result is a lightweight, maintainable site with instant load times and optimal SEO.

## Features

### Core Technologies
- Semantic HTML5 &mdash; Structure and accessibility first.
- Modern CSS3 &mdash; CSS custom properties, Flexbox, and responsive typography.
- Zero Dependencies &mdash; No frameworks, no build steps, and no bloated client-side JS runtime.

### Design & Experience
- Responsive Layout &mdash; Fluid design that adapts to any device size.
- Dark Mode &mdash; High contrast, eye-friendly dark theme with clean accents.
- Micro-interactions &mdash; Subtle CSS transitions and accessible focus states.

### Performance
- Lightweight &mdash; The entire site size is minimal, ensuring instant loading from CDN edge cache.
- Efficient Animations &mdash; Hardware-accelerated CSS animations with reduced-motion support.
